# ASALVoo Interpreta

### Interpretación bidireccional español dominicano – criollo haitiano

**Comunicación inteligente para acercar a las personas.**

ASALVoo Interpreta es una solución tecnológica del ecosistema **ASALVoo by @MujerSeguridad**, concebida para facilitar la comunicación bidireccional entre hablantes de español dominicano y criollo haitiano.

Su propuesta está orientada a ofrecer una experiencia de interpretación fluida y natural, con la posibilidad de utilizar las gafas inteligentes ASALVoo mediante conexión Bluetooth para escuchar las traducciones y facilitar la comunicación sin depender constantemente de la pantalla del teléfono.

## Características principales

- Interpretación bidireccional español dominicano ↔ criollo haitiano.
- Integración con las gafas inteligentes ASALVoo.
- Comunicación manos libres mediante dispositivos compatibles.
- Repertorio lingüístico ampliado de 8,908 expresiones.
- Reconocimiento y reproducción de voz.
- Búsqueda de expresiones por idioma y categoría.
- Sección de aprendizaje para explorar el repertorio.
- Experiencia adaptable a dispositivos móviles y computadoras.
